# Student Study Planner:

A simple and responsive study planning web application designed to help students organize their daily study tasks, track completion, and monitor their progress.

## Live Demo:

https://emonsaharaj001.github.io/student-study-planner/

##  Features:

* Add study tasks
* Select subject and study duration
* Mark tasks as completed
* Delete tasks
* Automatic progress calculation
* Visual progress circle
* Task statistics
* LocalStorage data persistence
* Responsive design
* Smooth sidebar navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Git & GitHub
* GitHub Pages
